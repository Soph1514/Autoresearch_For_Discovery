Bin packing with a fixed bin capacity

Given a positive integer bin capacity and a finite list of positive integer item sizes, each at most the capacity, assign every item to a bin so that the total size in each bin is at most the capacity, using as few bins as possible. A feasible assignment always exists because each item fits in a bin of its own. The number of bins is at least ceil(sum of sizes / capacity), because the bins must together hold the whole total size and no bin holds more than the capacity. The minimum is not known in closed form for arbitrary inputs and deciding it is NP-hard, so we seek good feasible assignments rather than a proof of minimality.

Computational task: given capacity and sizes, solve(capacity: int, sizes: list[int]) -> list[int] returns a list of bin indices with one entry per item, in the same order as sizes. Entry i is the index of the bin holding item i. Bin indices are nonnegative integers and need not be contiguous. An assignment is feasible when its length equals the number of items, every entry is a nonnegative integer, and the total size assigned to each bin is at most the capacity. The metric bins_used is the number of distinct bin indices that hold at least one item, to MINIMIZE; aggregate by SUM across the fixed evaluation suite. Relabelling or renumbering bins does not change bins_used, so index gaps neither help nor hurt. Python standard library only is available in the isolated evaluator. Deterministic construction and optimization methods should work for any capacity and any item sizes; do not hardcode evaluation cases.

Formalize the general problem as definitions and the finite computational contract, including feasibility and bins_used. Do not assert that any particular assignment is minimal and do not attempt to prove that the minimum is attained by a specific construction. Define the desired solve relation as a specification, not a claim that a generated Python implementation is verified. Use Lean 4.19 and import Mathlib. Preserve the Python interface solve(capacity: int, sizes: list[int]) -> list[int] and objective metadata (minimize bins_used, sum aggregation) in comments for interface extraction.
