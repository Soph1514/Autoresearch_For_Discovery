Sidon sets: minimizing the autoconvolution constant

Let C be the largest constant such that sup_{-1/2 <= t <= 1/2} integral_R f(t-x) f(x) dx >= C (integral_{-1/4}^{1/4} f(x) dx)^2 for every nonnegative measurable integrable f with positive finite mass on [-1/4,1/4]. The exact optimum is open. We seek explicit upper-bound witnesses, not a proof of the optimal C. Restricting to functions supported on [-1/4,1/4] suffices: truncation preserves the denominator and can only decrease the numerator.

Computational task: given n (2 <= n <= 4096), solve(n: int) -> list[int] returns n nonnegative integers q, not all zero. The height on cell i of width 1/(2n) is q[i]/2^40, with zero outside [-1/4,1/4]. The squared integral must be >= 1/10^8. Define the discrete convolution a[k] = sum over 0<=i<n with 0<=k-i<n of q[i]*q[k-i], for 0<=k<2n-1. The metric c1 is 2*n*max(a)/(sum(q))^2, to MINIMIZE; aggregate by MEAN across the fixed evaluation suite. This is the exact continuous ratio for these step functions because the convolution is piecewise linear and its maxima occur at the grid knots.
